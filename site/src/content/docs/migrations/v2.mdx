This guide should include everything you need to know in order to upgrade `eslint-plugin-package-json` from v1 to v2.

<Aside type="note">Psst, it's not a lot...</Aside>

## `jsonc-eslint-parser` to `@eslint/json`

The biggest change in v2, and the one that this guide was originally intended to help you through is the shift from using `jsonc-eslint-parser` as a parser, to using the official `json` language provided by `@eslint/json`.
The steps are broken down by type of usage.

- If your primary usage of the plugin is through one or more of its configs, then check out the first section.
- If you don't use any our configs, and you set up the parser and directly enable some set of our rules, then the second section is for you.

### Config Usage

If you're using any of our configs, and aren't setting up the `parser` manually, then there's genuinely nothing for you to do, other than upgrade this package.
We've installed `@eslint/json` and set up the language in the config.
Congrats for being cool 😎.

### No-config Usage

If you previously set up the plugin and `parser` manually to enable some subset of our rules, then you'll have a little more to do.
You just need to remove the `parser` configuration, and add the `language`.

```diff
{
  files: ['**/package.json'],
- languageOptions: {
-   parser: parserJsonc,
- },
+ language: 'json/json',
  plugins: {
    'package-json': packageJson,
  },
  rules: {
    'package-json/order-properties': 'error',
  },
},
```

<Aside type="tip">
  If you're no longer using `jsonc-eslint-parser` for some other purpose, you can safely uninstall
  it.
</Aside>

## Updated ESLint and Node Support

v2 of the plugin now requires a version of Node.js in the following range `^24.15.0 || >= 26.12.0"`.
We've also updated the minimum supported version of ESLint to `9.15.0`.
You'll need to update your environment accordingly, if you're using versions outside of this range.

## Updates to Configs

### New Recommended Rules

The following rules have been added to the `recommended` config.

- `consistent-property-aliases` ([Docs](https://eslint-plugin-package-json.dev/rules/consistent-property-aliases/))
- `no-local-dependencies` ([Docs](https://eslint-plugin-package-json.dev/rules/no-local-dependencies/))
- `require-package-json-export` ([Docs](https://eslint-plugin-package-json.dev/rules/require-package-json-export/))

### `recommended-publishable` Removed

The deprecated `recommended-publishable` config has been removed.
It was identical to the `recommended` config, and so you can safely switch to using that instead.

```diff
{
- extends: [packageJson.configs['recommended-publishable']],
+ extends: [packageJson.configs.recommended],
  files: ['**/package.json'],
},
```

### Rule Removals

- `sort-collections` was removed from the `recommended` config
- `order-properties` was removed from the `stylistic` config

If you'd like to continue using these rules, you can enable them manually in your configuration.

```diff
{
  extends: [packageJson.configs.recommended, packageJson.configs.stylistic],
  files: ['**/package.json'],
+ rules: {
+   'order-properties': 'error',
+   'sort-collections': 'error',
+ },
},
```

## Updates to Rules

### `exports-subpaths-style`

The `exports-subpaths-style` rule now applies to `publishConfig.exports` as well as the top-level `exports` property.

<Tabs>
<TabItem label="❌ Incorrect">

```json
{
  "exports": "./index.ts",
  "publishConfig": {
    "exports": "./index.js"
  }
}
```

```json
{
  "exports": {
    "import": "./index.mts",
    "require": "./index.cts"
  },
  "publishConfig": {
    "exports": {
      "import": "./index.mjs",
      "require": "./index.cjs"
    }
  }
}
```

</TabItem>
<TabItem label="✅ Correct">

```json
{
  "exports": {
    ".": "./index.ts"
  },
  "publishConfig": {
    "exports": {
      ".": "./index.js"
    }
  }
}
```

```json
{
  "exports": {
    ".": {
      "import": "./index.mts",
      "require": "./index.cts"
    }
  },
  "publishConfig": {
    "exports": {
      ".": {
        "import": "./index.mjs",
        "require": "./index.cjs"
      }
    }
  }
}
```

</TabItem>
</Tabs>

See the [rule docs](https://eslint-plugin-package-json.dev/rules/exports-subpaths-style/) for more information.

### `sort-collections`

In addition to sorting object properties, `sort-collections` now also sorts arrays.

```diff
{
- "keywords": ["zebra", "apple", "banana"]
+ "keywords": ["apple", "banana", "zebra"]
}
```

See the [rule docs](https://eslint-plugin-package-json.dev/rules/sort-collections/) for more information.
