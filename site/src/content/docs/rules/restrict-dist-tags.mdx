This rule restricts npm dist-tags used in dependency declarations.

By default, it allows these commonly-used tags:

- `latest`
- `dev`
- `next`
- `alpha`
- `beta`
- `canary`
- `rc`

And other dist-tags are reported.

## Options

| Name         | Type                                                                                      | Default                     |
| ------------ | ----------------------------------------------------------------------------------------- | --------------------------- |
| `allowed`    | `('latest' \| 'dev' \| 'next' \| 'alpha' \| 'beta' \| 'canary' \| 'rc')[]`                | Common npm dist-tags        |
| `allowedFor` | `('dependencies' \| 'devDependencies' \| 'optionalDependencies' \| 'peerDependencies')[]` | All dependency types (`[]`) |

### `allowed`

Define the allowed dist-tags. **Use an empty array to disallow all dist-tags.**

```js
export default [
  {
    'package-json/restrict-dist-tags': [
      'error',
      {
        allowed: ['rc'],
      },
    ],
  },
];
```

With this configuration, only `rc` is allowed (for all dependency types).

### `allowedFor`

Limit the allowed dist-tags to specific dependency types.

```js
export default [
  {
    'package-json/restrict-dist-tags': [
      'error',
      {
        allowedFor: ['devDependencies'],
      },
    ],
  },
];
```

With this configuration, all common npm dist-tags are allowed in `devDependencies`, but any dist-tag is reported in `dependencies`, `optionalDependencies`, and `peerDependencies`.

You can also select multiple dependency types:

```js
export default [
  {
    'package-json/restrict-dist-tags': [
      'error',
      {
        allowedFor: ['dependencies', 'devDependencies'],
      },
    ],
  },
];
```

When both `allowed` and `allowedFor` are defined, the rule will only allow the specified dist-tags for the specified dependency types.

## Examples

```ts
// eslint.config.js
export default [
  {
    'package-json/restrict-dist-tags': [
      'error',
      {
        allowed: ['canary', 'rc'],
        allowedFor: ['devDependencies'],
      },
    ],
  },
];
```

This rule only checks bare dist-tag values. It ignores semver versions and ranges, workspace specifications, local paths, Git specifications, URLs, npm aliases, catalog specifications, and non-string dependency values.
